# Archives de recherche

Ces fichiers conservent l'historique expérimental. Ils ne constituent pas le
parcours recommandé ; commencer par le [README principal](../README.md).

| Dossier | Contenu |
|---|---|
| `diagnostics/` | Anciens tests LIF, décodeurs et validations exploratoires |
| `ppo_prototypes/` | Premiers essais d'apprentissage par renforcement et packages vides associés |
| `experiments/` | Anciennes démos 3D v4/v5, calibration et recherches ponctuelles de lecture neuronale |
| `demos/altitude_only.py` | Ancien `main.py`, démonstration classique de maintien d'altitude |

Les fichiers déplacés sont conservés octet pour octet. Certains imports ou chemins
historiques peuvent nécessiter leur environnement d'origine. Ils ne sont pas inclus
dans les vérifications du parcours actuel. Les restaurer depuis Git si nécessaire ;
ne pas utiliser leurs titres ou anciens commentaires comme preuve de stabilisation.
